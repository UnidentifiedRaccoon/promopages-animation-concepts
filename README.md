# Оживлённые изображения в настройке объявлений

[Открыть концепты](https://unidentifiedraccoon.github.io/promopages-animation-concepts/)

Три интерактивных варианта интерфейса управления готовыми анимациями изображений. Для первой реализации и проверки UX-гипотезы выбран **02 — «Картинка и крупный просмотр»**.

- `concept.html?variant=cards` — переключатель в карточке.
- `concept.html?variant=inspector` — сетка изображений и крупный предпросмотр.
- `concept.html?variant=review` — отдельная вкладка и групповое включение.

В каждом варианте работают просмотр видео, переключение статичной и живой версии, сохранение и отмена. Настройки сохраняются локально в браузере. Прототип не связан с рекламными кампаниями и не запускает генерацию.

Индекс содержит пользовательские пути, сравнение вариантов и правила поведения. В верхней полосе демо можно выбрать сценарий: смешанная подборка, все видео готовы, нет готовых видео, 12 изображений, ожидание и ошибка.

## Локальный просмотр

Из корня проекта: `python3 -m http.server 8766 --bind 127.0.0.1`, затем открыть `http://127.0.0.1:8766/`.

## Публикация

GitHub Pages публикует корень ветки `main`. Файл `.nojekyll` включает раздачу статических файлов без обработки Jekyll. Все ресурсы используют относительные пути.
